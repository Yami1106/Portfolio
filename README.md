## What this is

My personal portfolio — a dark, animated, single-page site showcasing 17 projects across robotics, computer vision, ML, and IoT. Built entirely from scratch with vanilla HTML, CSS, and JavaScript. No frameworks, no build tools, no bloat.

**[→ Visit the live site](https://yamiportfolio.netlify.app/)**

---

## Highlights

- **Animated starfield canvas** with parallax mouse tracking
- **Live scroll spy** — nav bubble tracks your position as you scroll
- **17 project cards** with filterable categories (Robotics / ML / CV / IoT) and direct GitHub links
- **Detailed project modals** — full technical specs, benchmarks, and results on click
- **Dark / light theme** toggle with localStorage persistence
- **Contact form** powered by Formspree (no backend needed)
- **Two resume variants** — Robotics and Computer Vision tracks
- Fully **responsive** for mobile and desktop
